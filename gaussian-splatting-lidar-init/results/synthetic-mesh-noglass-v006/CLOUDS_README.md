# 已核验的无透明玻璃点云

两份普通彩色 PLY 均已回读并逐点核验。

| 用途 | 文件 | 点数 |
|---|---|---:|
| 虚拟视图初始化 | 1 cm（本地文件 `cloud_1cm/points_mesh_1cm_noglass.ply`） | 7,004,696 |
| 后续正式训练初始化 | 3 cm（本地文件 `cloud_3cm/points_mesh_3cm_noglass.ply`） | 797,520 |

单位为米。二进制小端 PLY，XYZ 与 nx/ny/nz 为 float32，RGB 为 uint8 sRGB。每点带有来源索引 sidecar，能追溯到原网格三角面和原训练图像；不需要图像分割模型。

源场景已有材质自定义标签 `semantic_class=clear_glass`，实际透射权重为1。排除33个透明玻璃部件上176,124个采样点，保留2055个非玻璃部件。详见 [排除判定](audit/semantic_decision.json) 和 [独立检查](cloud_verification.json)。塑料、电视屏幕与控制面板等未按名称误排除。

1 cm保留原确定性采样的所有非玻璃点。3 cm对其按每部件世界坐标体素选取真实表面代表点，是1cm的精确子集。两者为体素采样分辨率，不保证严格最小点距。所有保留点的原XYZ/RGB/法向不变，未重新拟合颜色。

新3cm为完整mesh表面采样，与旧的309,240点训练RGB-D融合云来源不同。用户已指定这个新文件作为后续正式训练初始化；旧文件仍保留，尚未开始正式训练或覆盖旧数据集sparse文件。

取色仍使用原训练视图与原材质底色回退。玻璃后方的实体也可能保留未观测颜色；去玻璃不等同于重新烘焙光照/纹理，也不是物理激光回波模拟。本轮无新增玻璃图像mask，虚拟图仍保留原覆盖mask规则。

200张虚拟视图的渲染和验证状态以本目录最终 `verification.json`、`README.md` 为准；本文件只确认两份点云。
