## 质量限制与证据

003193 的玻璃柜在本轮变成白色遮挡。其 PSNR 为 4.4809 dB，间隙仅 0.1657%，应用当前有效 mask 后 PSNR 仍为 4.4738 dB。掩膜无法过滤这些有覆盖但外观错误的像素。


完整 mesh 包含 16 个柜门玻璃部件，共采样 92614 个点；其中 92514 个点使用接近白色的材质底色，RGB 中位数为 [250,253,252]。这些点与其他部件一样初始化为接近 1 的不透明度。白色玻璃点遮挡柜内物体的机制与渲染失败一致。具体证据见 `quality_review.json`。

本轮实验按既定配置完成，但不能标记为整体外观通过，也不建议不加区分地作为高质量伪真值加入训练。后续应单独处理透明玻璃表面点或增加语义有效掩膜，然后作为新配置复测。本轮输入、尺度、不透明度和原始输出全部保留。

`full/` 是渲染数据根；`metrics/per_view_metrics.csv` 是 200 张逐图指标；`metrics/full200_vs_3cm_scale05.csv` 是两个已完成全量版本的逐图对照；`reproducibility/` 保存实际执行的 notebook 和环境日志。
